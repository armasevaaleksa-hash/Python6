## 2. Контрольне запитання

**Запитання:** Як можна імпортувати всі функції з модуля, не використовуючи оператор *?

**Відповідь:**

Щоб імпортувати всі потрібні функції з модуля без використання оператора *, можна явно перелічити їхні назви через кому.

from calculator.basic_operations import add, subtract, multiply, divide

Також можна імпортувати весь модуль:

from calculator import basic_operations
result = basic_operations.add(5, 3)

У такому випадку доступ до функцій здійснюється через назву модуля.
Цей спосіб дозволяє уникнути конфліктів імен, робить код зрозумілішим та полегшує його підтримку.
